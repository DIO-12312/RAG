# DeepDoc PDF 增量实施计划

## 范围

本增量只改变 PDF 摄取链路。文本型 PDF 使用原生文字与坐标解析；扫描页在原生文字不足时使用 Poppler 渲染和 Tesseract OCR；CHM、CHI、Markdown、文本和代码解析保持不变。

## 工作包

1. 增加 `plain / deepdoc / auto` 模式、OCR 安全边界和配置摘要版本。
2. 以 PDF 原生坐标恢复阅读顺序、标题层级、页眉页脚和表格型行，并输出可追溯版面元数据。
3. 对扫描页按需执行受限 OCR，缺少工具或执行失败时返回稳定错误，不静默伪造解析成功。
4. 补齐单元、契约和容器测试；使用文本型、双栏/表格型和扫描型 fixture 验证。

## 非目标

- 不引入第二套检索引擎或 HTTP API。
- 不复制 RAGFlow DeepDoc 源码或模型权重。
- 本阶段不实现图片语义理解、公式识别或端到端神经网络版面模型。
