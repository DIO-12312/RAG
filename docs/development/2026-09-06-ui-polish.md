# 前端视觉与动效迭代

视觉方向：简洁留白的个人知识工作空间。参考本地 RAGFlow 的导航分组与层级思想；以 banner-design 的单焦点构图处理欢迎区，配合 UI/UX Pro Max 的 Minimalism & Swiss Style 建议，保留项目紫色主色，用暖白、灰紫侧栏和少量桃色/薄荷色区分功能。图标和知识插图为新写的 SVG/CSS，不复制参考项目源码。

覆盖概览、知识库、详情与上传、对话、设置、登录。概览提供三个真实入口；数据卡片使用真实文档数和状态。对话页提供多行输入和可编辑的提问建议，保留原有 HTTP/SSE、停止生成、会话与完整证据功能。未更改 Go/Python API。

动效：Vue 页面进入/退出、卡片分步出现和悬停抬升、知识图形的分层进入、按钮按压、输入框聚焦、检索状态圆点及引用展开。装饰动画一次完成；只有等待状态动画持续。系统 prefers-reduced-motion 开启后禁用动画和过渡。使用原生 CSS，无动画运行时依赖。小屏输入框使用正常文档流，避免覆盖快捷提问；桌面对话记录下输入框保持可见。

验收：前端 lint、14 项既有测试和生产构建（含类型检查）通过。使用隔离的浏览器及合成 API 数据检查 1440px 桌面、768px 平板、375px 手机和 812×375 横屏的概览/知识库/详情/对话/设置；核验无水平溢出、快捷问题填入、SSE 回答显示、完整引用展开、减少动态效果以及无页面异常。浏览器测试未使用真实密钥，也未创建或改写真实账号、知识库、会话。当前仅交付浅色主题，未宣称暗色模式验收。
